# Testing Patterns with Vitest

## What is this skill?

This skill documents testing patterns and conventions used in Cipher Draw with Vitest, including unit tests, async tests, React component tests, and store tests.

## When to apply this skill

- Writing tests for new features
- Testing utilities and renderers
- Testing React components
- Testing Zustand stores
- Debugging failing tests
- Improving test coverage
- Setting up test infrastructure

## Key concepts covered

- Vitest configuration
- AAA pattern (Arrange, Act, Assert)
- Unit testing pure functions
- Async testing
- React component testing
- Zustand store testing
- Mocking and spying
- Coverage targets
- Testing best practices
