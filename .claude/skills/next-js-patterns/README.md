# Next.js 14 App Router Patterns

## What is this skill?

This skill contains patterns and conventions for Next.js 14 with App Router used in the Cipher Draw project.

## When to apply this skill

- When creating new pages or routes
- When deciding between client and server components
- When setting up layouts or metadata
- When working with dynamic routes
- When debugging Next.js-specific issues

## Key concepts covered

- App Router file structure
- Client vs Server Components
- Dynamic routing with `[param]`
- Metadata and SEO
- Path aliases with `@/`
- Build and dev commands
