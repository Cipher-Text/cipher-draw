# Zustand State Management Patterns

## What is this skill?

This skill documents Zustand state management patterns used in Cipher Draw, including store creation, persistence, selective subscriptions, and common pitfalls.

## When to apply this skill

- Creating or modifying Zustand stores
- Adding new state or actions
- Optimizing component re-renders
- Implementing state persistence
- Debugging state-related issues
- Syncing state with URL or external sources

## Key concepts covered

- Store creation with TypeScript
- Persist middleware for localStorage
- Selective subscriptions
- Action patterns
- Anti-patterns to avoid
- Testing stores
